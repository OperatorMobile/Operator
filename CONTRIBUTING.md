# Contributing

Operator is not accepting general external contributions until the Android
runtime architecture and public release process stabilize.

For now:

- Open issues for reproducible bugs, build failures, and documentation gaps.
- Keep proposed patches small and focused.
- Do not submit secrets, signing keys, local SDK paths, generated APKs, runtime
  SDK archives, or bundled binary artifacts.
- Preserve upstream notices for Codex, Android runtime sources, toolchains, and
  third-party packages.

By contributing, you agree that your contribution may be distributed under this
repository's license terms.
